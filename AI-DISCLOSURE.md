# AI Use Disclosure

Our course allows AI tools but requires disclosure. This file records what was AI-generated
and what the team decided. **Add a row to the log every time AI contributes to the project.**

## Entry 1: starter scaffold (2026-11-10)

- **Tool:** Claude Code (Anthropic), model Claude Opus 5.5, run inside VS Code.
- **Requested by:** David Valle.
- **Prompt summary:** Build a bare-bones, accessible, mobile-first starter layout (plain HTML/CSS/JS)
  for our modular character-sheet design, split so three people can work in parallel.

### Decided by the team (given to the AI as requirements)

- The conceptual model: arrangeable cards ordered by frequency of use, 7 modules, card order = screen-reader order.
- The screens and zones from our low-fi prototype: Hub, Card view, Quick Page overlay, and the bottom
  action bar (Quick Page · Roll · Level Up). The name "Quick Page".
- AC first in Combat. Collapsible cards. Move up/down reordering. Accessibility requirements
  (semantic landmarks, keyboard, aria-expanded, focus management, Escape, rem units).
- Stack: plain HTML/CSS/JS, no framework. Separate data file. README with a work split.

### Generated by the AI

Every file in the initial commit was written by the AI:

| File(s) | What it is |
|---|---|
| `index.html` | Page shell, zones, Quick Page `<dialog>` |
| `css/base.css`, `css/layout.css`, `css/cards.css`, `css/quick-page.css` | Placeholder styles, responsive grid, focus styles |
| `js/registry.js` | Namespace, card registry, helpers |
| `js/hub.js`, `js/router.js`, `js/quick-page.js`, `js/app.js` | Hub rendering, collapse, reorder, routing, overlay |
| `js/cards/*.js` (7 files) | Placeholder card modules |
| `js/actions/roll.js`, `js/actions/level-up.js` | Stub buttons |
| `js/data/sample-character.js` | Sample character "Kira" (stats, features, backstory text) |
| `README.md`, `AI-DISCLOSURE.md` | Documentation |

### Design choices the AI made (review these as a team)

- Classic `<script>` tags instead of ES modules, so the page works from `file://`.
- Hash routing (`#/`, `#/card/<id>`) for the Card view.
- *Edit layout* toggle that reveals Up/Down buttons (instead of always showing them), plus *Reset order*.
- Quick Page numbers follow the player's current hub order. Number keys 1–7 jump while it's open.
- Native `<dialog>` element for the Quick Page (built-in focus containment and Escape).
- Placeholder color palette and the sample character's specific values and backstory.
- The suggested split of work (Person A/B/C mapped to the three test tasks).
